# FinSight---Financial-Analysis-Project

An interactive **Finance Analytics Dashboard** built in **Power BI** to monitor financial transactions, customer behavior, fees, taxes, and business performance across multiple customer segments and regions.

## 📌 Project Overview

This project provides a centralized analytics solution for financial organizations to:

- Track overall financial performance
- Monitor monthly transaction trends
- Compare successful, failed, and pending transactions
- Analyze customer segments and demographics
- Evaluate state-wise business performance
- Measure fees, taxes, and transaction profitability
- Support data-driven business decisions

---

## 🎯 Business Objectives

The dashboard helps stakeholders:

- Monitor KPIs in real time
- Identify high-performing customer segments and states
- Analyze transaction patterns and yearly trends
- Track operational fees and tax collection
- Understand customer demographics
- Improve financial strategy and decision-making

---

## 📊 Key Performance Indicators (KPIs)

| KPI | Description |
|------|-------------|
| **Total Amount** | Total value of all transactions with YoY growth |
| **Total Transactions** | Number of transactions processed |
| **Average Transaction Value** | Average amount per transaction |
| **Total Fees** | Total fees collected |
| **Total Tax** | Total tax generated |

# 📈 Dashboard 1 – Executive Overview

### 1. Monthly Transaction Trend
- **Chart:** Line / Area Chart
- Tracks transaction amount across months
- Identifies seasonal spikes and declines

### 2. Transaction Status Analysis
- **Chart:** Donut Chart
- Categories:
  - Success
  - Failed
  - Pending
- Measures operational efficiency

### 3. Customer Segment Contribution
- **Chart:** Horizontal Bar Chart

Segments:
- Retail
- Premium
- SME
- Corporate
- Wealth

Shows which customer groups generate the highest transaction value.

### 4. State-wise Performance
- **Chart:** Horizontal Bar Chart

Compares transaction amounts across different states to identify top-performing regions.

### 5. Transaction Type Analysis
- **Chart:** Matrix / Heatmap

Metrics Included:
- Amount
- Fees
- Tax
- Transaction Count

Transaction Types:
- Bill Payment
- Card Payment
- Deposit
- Fee Charge
- Interest Credit
- Investment
- Loan EMI
- Refund
- Transfer
- Withdrawal

### 6. Gender Analysis
- **Chart:** Donut Chart

Compares transaction contribution by:
- Male
- Female
